# MAFIA NYC — контент-бот

Каждый день делает готовые материалы для Instagram в едином стиле (чёрный / красный / кремовый нуар):
сторис, афиши игры, Reels со своим звуком и тексты подписей с хэштегами.

## Запуск

```
python3 make.py                    # материалы на сегодня -> output/<дата>/
python3 make.py --date 2026-12-04  # на конкретный день
python3 make.py --week --no-reel   # быстрый просмотр всей недели без видео
python3 make.py --spec today.json  # свежие тексты на сегодня (см. ниже)
```

Нужно: Python 3.10+, `pillow numpy scipy`, `ffmpeg`, шрифты Fira Sans и Lora
(пути задаются переменными `MAFIA_FONTS` и `MAFIA_LORA`).

## Свежие тексты: today.json

Если передать `--spec`, бот берёт тексты из файла, а не из `content/library.json`:

```json
{
  "stories": [
    {"type": "fact", "title": "СОВЕТ НОВИЧКУ", "text": "..."},
    {"type": "countdown"}
  ],
  "poster": "4x5",
  "poster_extra": "Новичкам — объясним правила",
  "poster_caption": "...",
  "reel": {"id": "custom", "caption": "...", "scenes": [ ... ]}
}
```

Типы сторис: `countdown`, `gameday` (line), `role` (role, text), `fact` (title, text),
`question` (question), `quote` (quote, author), `thanks` (text).
Роли для карт: МИРНЫЙ, ДОКТОР, ШЕРИФ, МАФИЯ, ДОН, МАНЬЯК, ЛЮБОВНИЦА.

Сцены Reels описаны в начале `engine/reel.py`: clock, city, table, flip, wake, seat, text, end.
Длина сцены — 2.5–4 сек, кратно 0.5. Последняя сцена — всегда `end`.
Текст в сценах — КАПСОМ, коротко: l1 до ~16 символов, l2 до ~14.

## Настройки бренда

Ник, день, время, место и способ записи — в `BRAND` в `engine/core.py`.
Тексты, хэштеги и готовые сценарии Reels — в `content/library.json`.
